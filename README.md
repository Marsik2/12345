# XiveVisuals — Fabric 1.21.4 (клиентский мод)

Визуал: космическое небо (4 палитры), звёзды, чёрная дыра, частицы.
Плюс HUD и помощники. Мод ничего не делает за игрока в бою
(нет аима, авто-ударов, увеличенной досягаемости, ESP, показа врагов сквозь стены).

## Управление
- Правый Shift — меню со всеми функциями (клик — вкл/выкл, наведите курсор — описание)
- Клавиши: V — палитра, B — частицы, H — HUD, C — приближение
- /xive — список функций; /xive <название> — вкл/выкл
- Метки: /xive wp add|del|list; таймеры: /xive timer <сек>; фильтр чата: /xive chatfilter add <слово>
- Настройки: config/xivevisuals.properties

## Сборка
GitHub Actions (вкладка Actions -> Build mod -> Artifacts) или IntelliJ IDEA + JDK 21 (Gradle -> build).
Нужны Fabric Loader 0.16.10+ и Fabric API 0.119.4+1.21.4.

## Важно
Правила серверов разные, гарантировать отсутствие бана нельзя — проверьте правила FunTime.
